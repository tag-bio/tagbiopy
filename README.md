# tagbiopy
## Python SDK and API wrapper for Tag.bio integration<br><br>

### Development
1. In a terminal, clone this repository and move to the project root
2. Create a new virtual environment for this project with ```uv venv```
3. Load the new environment with ```source .venv/bin/activate```
4. Build the project by executing ```uv build```
5. Install the newly built `tagbiopy` with ```uv pip install dist/tagbiopy-[ADD_VERSION_FROM_FILENAME]-py3-none-any.whl```
