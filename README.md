# Prerequisites

Make sure you have python 3.8 and related pip installed.
 
There are several ways python3 and pip3 can be installed:
 
1. With [brew](https://brew.sh)
2. From [Python Packaging Authority](https://pip.pypa.io/en/stable/installing). 
3. [JFGI](https://lmgtfy.com/?q=maco+osx+pip3+install&s=l)

It is recommended that this SDK gets installed into a virtualenv. However,
it could be also installed straight-up into the global namespace and directory
structure.

# Installation

## Without virtualenv
Clone this repo and change to its directory. 

```bash
pip install -e .

```

## With virtualenv

Create a virtualenv, i.e. `fc`. Then follow the outlined procedure without virtualenv.

And voilà!
